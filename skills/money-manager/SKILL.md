# Skill: Money Manager (المدير المالي الذكي)

## Description
مهارة متخصصة في إدارة المصروفات، الديون، الاستثمارات، والتخطيط المالي الشخصي. تتعامل مع جداول جوجل شيت وتوفر تحليلات ذكية، تنبيهات، وتوصيات مالية.

## Created By
- **المبدع:** أسترو 🤖✨ (الروبوت المساعد الذكي)
- **للمدير:** أحمد خالد
- **التاريخ:** 2026-03-15
- **السياق:** إدارة مصروفات شخصية مع ديون بالتقسيط واستثمارات

## Capabilities

### 1. قراءة وتحليل جداول جوجل شيت
- قراءة روابط جوجل شيت (View/Edit)
- استخراج وتحليل البيانات المالية
- فهم التصنيفات (ديون، مصروفات ثابتة، استثمارات، ترفيه)

### 2. تحليل الديون بالتقسيط
- تتبع أقساط الديون
- حساب تواريخ الانتهاء
- تحليل استراتيجية "الأقساط الكثيرة التي تقل مع الوقت"
- تقدير الفائض المالي بعد انتهاء الأقساط

### 3. إدارة الحسابات المتعددة
- تتبع الأموال في حسابات مختلفة (CIB، فوري، بنك القاهرة، كاش)
- تحليل التوزيع المالي
- اقتراحات لتحسين التوزيع

### 4. مراقبة الاستثمارات
- متابعة الاستثمارات الحالية
- اقتراح استراتيجيات استثمارية
- تحليل العائد المتوقع

### 5. نظام التنبيهات الذكي
- تنبيه قبل 3 أيام من سداد الأقساط
- تحذيرات عند اقتراب حدود الميزانية
- تذكير بالمبالغ المتبقية للديون

### 6. لوحة تحكم روبوتية
- عرض إحصائيات سريعة
- رسوم بيانية للمصروفات
- توقعات مالية للمستقبل

## Workflow

### الخطوة 1: قراءة الشيت
```bash
1. الحصول على رابط جوجل شيت
2. استخراج البيانات
3. فهم الهيكل العام
```

### الخطوة 2: التحليل الأساسي
```bash
1. حساب الإجماليات
2. تحليل التصنيفات
3. تحديد النقاط الحرجة
```

### الخطوة 3: التخطيط الاستراتيجي
```bash
1. خريطة نزول الديون
2. توقع الفائض المستقبلي
3. اقتراح تحسينات
```

### الخطوة 4: المتابعة المستمرة
```bash
1. تحديث البيانات دورياً
2. إرسال تقارير
3. تنبيهات ذكية
```

## Data Structure Understanding

### الأعمدة الرئيسية في شيت المدير أحمد خالد:
1. **Date** - تاريخ المصروف
2. **Item** - البند
3. **Quantity** - الكمية
4. **Unit Price** - سعر الوحدة
5. **Total** - الإجمالي
6. **Category** - التصنيف (ديون، مصروفات ثابتة، استثمارات)
7. **payment method** - طريقة الدفع
8. **Transaction Type** - نوع المعاملة

### التصنيفات الخاصة:
- **ديون** - الديون بالتقسيط
- **مصاريف ثابتة** - مصروفات منتظمة
- **استثمار** - استثمارات مالية
- **فيزا مشتريات** - مشتريات بالفيزا
- **ترفيه** - مصروفات ترفيهية
- **سحور** - مصروفات السحور
- **جبن والبان** - منتجات الألبان
- **مشتريات منزلية** - مشتريات البيت

## Special Notes

### استراتيجية المدير أحمد خالد:
- **ديون بالتقسيط** - اختيار استراتيجي للحفاظ على السيولة
- **أقساط كثيرة** - ولكنها تقل واحدة واحدة مع الوقت
- **مرتب فيزلو** - غير محسوب في الشيت، مما يعني دخل أعلى
- **التسجيل الدقيق** - كل مصروف مسجل بدقة

### روح المهارة:
- **ساخرة وعملية** - مزج بين الفكاهة والكفاءة
- **ذكية ومبتكرة** - حلول مبتكرة للمشاكل المالية
- **مبادرة** - اقتراح تحسينات دون انتظار الطلب
