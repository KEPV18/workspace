# 📚 دليل استخدام محسن التكلفة الافتراضي

## 🔧 نظرة عامة

**محسن التكلفة الافتراضي** هو نظام يعمل تلقائياً لتحسين استخدام النماذج وتقليل التكاليف في OpenClaw. يعمل مع بداية كل جلسة دون الحاجة إلى استدعاء يدوي.

## 🚀 البدء السريع

### التشغيل التلقائي
- المهارة تعمل **تلقائياً** عند بدء OpenClaw
- لا تحتاج إلى أي إعداد يدوي
- تبدأ في تحليل وتخصيص النماذج فوراً

### الأوامر المتاحة
```
أعرض إحصائيات التكلفة        # عرض إحصائيات الاستخدام والتكلفة
تحقق من الميزانية            # التحقق من حالة الميزانية الحالية
ضبط نموذج [اسم النموذج]     # تغيير النموذج الافتراضي يدوياً
عطّل المحسن مؤقتاً          # تعطيل التحسين التلقائي مؤقتاً
فعّل المحسن                 # إعادة تفعيل التحكم التلقائي
```

## 📊 كيفية العمل

### 1. **تحليل التعقيد**
- يحلل كل طلب لتقدير تعقيده (0.0 إلى 1.0)
- يأخذ في الاعتبار: الطول، الكلمات المفتاحية، الهيكل
- يحدد مستوى التعقيد: بسيط، متوسط، معقد

### 2. **اختيار النموذج**
- **مهام بسيطة**: `glm-4.7-flash` أو `gemini-2.5-flash-lite`
- **مهام متوسطة**: `gpt-5-nano` أو `grok-3-mini`
- **مهام معقدة**: `deepseek-v3.2` أو `sonar`

### 3. **تتبع التكلفة**
- يحسب التكلفة المتوقعة لكل طلب
- يسجل التكاليف الفعلية
- يحذر عند اقتراب حدود الميزانية

## ⚙️ التخصيص

### تعديل الإعدادات
يمكن تعديل الإعدادات في:
```
~/.openclaw/workspace/cost_optimizer_config.json
```

### الإعدادات القابلة للتعديل
```json
{
  "budget_limit": 10.0,           # الميزانية الشهرية بالدولار
  "auto_select": true,            # الاختيار التلقائي للنماذج
  "complexity_analysis": true,    # تحليل التعقيد
  "warnings_enabled": true,       # تفعيل التحذيرات
  "learning_enabled": true        # التعلم من الأنماط
}
```

## 📈 مراقبة الأداء

### الإحصائيات الرئيسية
- **إجمالي التكلفة**: المبلغ الإجمالي المنفق
- **الإنفاق الشهري**: التكلفة خلال الشهر الحالي
- **عدد الطلبات**: إجمالي الطلبات المعالجة
- **النماذج الأكثر استخداماً**: ترتيب النماذج حسب التكلفة

### التقارير
- تقرير أسبوعي تلقائي
- تحذيرات عند تجاوز العتبات
- اقتراحات للتحسين

## 🔍 استكشاف الأخطاء

### المشكلات الشائعة
1. **المحسن لا يعمل**
   - تحقق من وجود ملف `startup_log.json`
   - تأكد من صلاحيات الملفات

2. **التكاليف غير مسجلة**
   - تحقق من اتصال الإنترنت
   - تأكد من صلاحية مفتاح OpenRouter API

3. **تحذيرات الميزانية لا تظهر**
   - تحقق من إعداد `warnings_enabled`
   - تأكد من صحة تنسيق ملف التكاليف

### سجلات النظام
```
~/.openclaw/workspace/skills/cost-optimizer-default/startup_log.json
~/.openclaw/workspace/skills/cost-optimizer-default/cost_tracker.json
```

## 🎯 أفضل الممارسات

### لتقليل التكلفة
1. استخدم `glm-4.7-flash` للمهام اليومية
2. استفد من `gemini-2.5-flash-lite` للمهام الطويلة
3. احتفظ بـ `deepseek-v3.2` للمهام المعقدة فقط

### لتحسين الجودة
1. استخدم `gpt-5-nano` للمهام الدقيقة
2. استخدم `sonar` لطلبات البحث
3. استخدم `grok-3-mini` للمحادثات السريعة

## 🤝 التكامل مع مهارات أخرى

### مع Smart Router
- المحسن الافتراضي يعمل كطبقة أساسية
- Smart Router يضيف تحليلات متقدمة
- التعاون ينتج توفيراً أكبر

### مع OpenRouter Orchestrator
- المحسن يختار النموذج الرئيسي
- Orchestrator يقسم المهام المعقدة
- النتيجة: تحسين مزدوج للتكلفة

## 📞 الدعم والمساعدة

### للحصول على المساعدة
1. راجع هذا الدليل أولاً
2. تحقق من سجلات النظام
3. استخدم الأمر `أعرض إحصائيات التكلفة`

### للإبلاغ عن مشاكل
- تحقق من تحديثات المهارة
- تأكد من توافق الإصدارات
- قدم تقريراً مفصلاً عن المشكلة
