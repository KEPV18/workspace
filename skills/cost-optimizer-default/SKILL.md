# 🔧 Cost Optimizer Default

**المُحسِّن الافتراضي للتكلفة والنماذج**

مهارة افتراضية تعمل تلقائياً عند بدء أي جلسة، تتحكم في اختيار النماذج وتقليل التكاليف بناءً على تعقيد المهمة والميزانية.

## 📋 الميزات الرئيسية

### 🎯 **اختيار النموذج الذكي**
- يختار النموذج الأمثل بناءً على تعقيد المهمة
- يستخدم `glm-4.7-flash` للمهام البسيطة والمتوسطة
- يترقى إلى نماذج أقوى للمهام المعقدة

### 💰 **التحكم في التكلفة**
- يحسب التكلفة المتوقعة لكل طلب
- يحترم الميزانية المحددة
- يسجل التكاليف الفعلية للتعلم

### 🔄 **التشغيل التلقائي**
- يعمل تلقائياً مع بدء أي جلسة
- لا يحتاج إلى استدعاء يدوي
- متكامل مع إعدادات النظام الافتراضية

## ⚙️ كيفية العمل

1. **عند بدء الجلسة**: تتحقق من النموذج الافتراضي (`glm-4.7-flash`)
2. **عند كل طلب**: تحلل تعقيد المهمة
3. **اختيار النموذج**:
   - مهام بسيطة: `glm-4.7-flash`
   - مهام متوسطة: `glm-4.7-flash` أو `gemini-2.5-flash-lite`
   - مهام معقدة: `deepseek-v3.2` أو `gpt-5-nano`
4. **تسجيل التكاليف** للتحليل المستقبلي

## 📊 قاعدة التكلفة

| النموذج | تكلفة الإدخال/رمز | تكلفة الإخراج/رمز | الاستخدام المقترح |

| `gemini-2.5-flash-lite` | 0.000000075 | 0.0000003 | بديل اقتصادي |

| `deepseek-v3.2` | 0.00000032 | 0.00000089 | للمهام المعقدة |
